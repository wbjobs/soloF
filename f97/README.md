# UDP 可靠文件传输系统

基于自定义 UDP 可靠协议的文件传输系统，实现了类似 TCP 的可靠传输机制，包括滑动窗口、超时重传、AIMD 拥塞控制等。

## 架构设计

```
┌─────────────┐           UDP            ┌─────────────┐
│  浏览器端   │ ───────────────────────> │  接收端     │
│  (上传页面) │                          │  (监控页面) │
└──────┬──────┘                          └──────┬──────┘
       │ HTTP/WS                                 │ HTTP/WS
       ▼                                         ▼
┌──────────────────┐        UDP         ┌──────────────────┐
│  Node.js 发送端  │ ─────────────────> │  Node.js 接收端  │
│  (分片/重传/AIMD)│                     │ (重组/ACK/状态)  │
└──────────────────┘                     └──────────────────┘
```

## 核心功能

### 可靠传输协议
- **分片机制**: 每片 1KB，支持大文件传输
- **序列号**: 32位序列号，确保有序传输
- **ACK 累积确认**: 接收端累计确认已接收的分片
- **超时重传**: 基于 RTT 动态计算 RTO，超时自动重传
- **快速重传**: 收到3个重复 ACK 立即重传
- **滑动窗口**: 动态窗口大小，流量控制

### 拥塞控制 (AIMD)
- **慢启动**: cwnd < ssthresh 时，每个 ACK cwnd +1
- **拥塞避免**: cwnd >= ssthresh 时，每个 RTT cwnd + 1/cwnd
- **拥塞发生**: 超时或3次重复 ACK 时，ssthresh = cwnd/2
- **超时恢复**: cwnd 重置为初始值

### 断点续传
- **位图记录**: 每8个分片用1字节位图记录接收状态
- **状态持久化**: 接收端自动保存 `.state` 文件
- **自动恢复**: 重传同一文件时自动加载已有状态

### 实时监控
- **Socket.IO 实时推送**: 毫秒级更新
- **吞吐量趋势图**: 最近30个样本可视化
- **重传统计**: 重传率、丢包率实时计算
- **拥塞控制参数**: cwnd, ssthresh, RTT, RTO 实时显示

## 快速开始

### 安装依赖
```bash
npm install
```

### 启动接收端
```bash
npm run receiver
# 或
node receiver/server.js

# 环境变量可选:
# UDP_PORT=41234 HTTP_PORT=3001 node receiver/server.js
```

接收端启动后，访问 `http://localhost:3001/receiver.html` 查看监控页面。

### 启动发送端
```bash
npm run sender
# 或
node sender/server.js

# 环境变量可选:
# UDP_HOST=127.0.0.1 UDP_PORT=41234 HTTP_PORT=3000 node sender/server.js
```

发送端启动后，访问 `http://localhost:3000` 进行文件上传。

### 运行测试
```bash
npm test
# 或
node test/speed-test.js
```

## 使用说明

### 通过浏览器上传
1. 确保接收端和发送端都已启动
2. 访问发送端页面 `http://localhost:3000`
3. 选择文件或拖拽文件到上传区域
4. 点击「开始传输」
5. 实时查看传输进度、吞吐量、拥塞控制参数
6. 可随时暂停、继续或取消传输

### 在接收端查看
1. 访问 `http://localhost:3001/receiver.html`
2. 查看实时传输状态、吞吐量趋势图、重传趋势图
3. 查看传输历史记录
4. 查看已接收文件列表

### 断点续传
1. 传输中断后（如关闭发送端），重新上传同一文件
2. 接收端会自动检测到已接收的分片
3. 仅传输未完成的分片，节省时间

## API 接口

### 发送端 API

#### POST `/api/upload`
上传并发送文件
- `Content-Type: multipart/form-data`
- 参数: `file` (文件)
- 返回: 传输启动状态

#### POST `/api/pause`
暂停当前传输

#### POST `/api/resume`
继续已暂停的传输

#### POST `/api/cancel`
取消当前传输

#### GET `/api/status`
获取当前传输状态

#### GET `/api/config`
获取配置信息

### 接收端 API

#### GET `/api/status`
获取当前传输状态和历史

#### GET `/api/files`
获取已接收文件列表

#### GET `/api/config`
获取配置信息

## 性能调优参数

在 `common/ReliableUDPSender.js` 中可调优:

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `initialCwnd` | 10 | 初始拥塞窗口 |
| `ssthresh` | 128 | 慢启动阈值 |
| `rtoMin` | 200 | 最小 RTO (ms) |
| `rtoMax` | 60000 | 最大 RTO (ms) |
| `windowSize` | 100 | 最大窗口大小 |

启动时也可通过参数传入:
```javascript
const sender = new ReliableUDPSender({
  host: '127.0.0.1',
  port: 41234,
  initialCwnd: 20,
  ssthresh: 256,
  rto: 100,
});
```

## 设计特点

1. **类 TCP 可靠性**: 实现了 TCP 的核心可靠机制，但运行在 UDP 之上
2. **UDP-like 行为**: 底层使用 UDP socket，无内置流量控制，完全由应用层实现
3. **拥塞控制友好**: AIMD 算法确保网络公平性
4. **实时可视化**: Socket.IO 推送到前端，毫秒级更新
5. **断点续传**: 自动检测已接收分片，支持大文件中断恢复
6. **跨平台**: 纯 Node.js 实现，支持 Windows/macOS/Linux

## 与 WebRTC DataChannel 的关系

本项目实现了类似 WebRTC DataChannel 的可靠 UDP 传输:
- **相同点**: 基于 UDP，支持可靠/不可靠模式
- **不同点**: 
  - 浏览器限制无法直接使用 UDP socket，因此使用 Node.js 辅助服务
  - 自定义协议栈，完全可控
  - 支持浏览器 -> Node.js -> UDP -> Node.js -> 浏览器 的传输路径
- **强制 UDP-like 行为**: 即使底层是 UDP，通过自定义协议实现可靠性

## 注意事项

1. **防火墙**: 确保 UDP 端口（默认 41234）在防火墙中开放
2. **MTU**: 分片大小 1KB 小于标准 MTU (1500)，避免 IP 分片
3. **跨主机**: 跨网络传输时需调整 RTO 参数
4. **并发**: 当前实现单文件传输，如需并发需修改队列逻辑
5. **校验和**: 可选实现文件校验和验证
