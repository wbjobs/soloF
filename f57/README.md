# 网络流量分析系统

基于图数据库的网络流量分析系统，使用 Neo4j 存储 NetFlow 数据，通过 PageRank 和 Louvain 社区发现算法识别核心节点和异常集群。

## 系统架构

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  NetFlow 数据   │────▶│   Neo4j 图数据库 │────▶│   图分析算法     │
│    生成器       │     │   (IP节点/通信边)│     │ PageRank/Louvain│
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                          │
                                                          ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   D3.js 可视化   │◀────│   Flask API     │◀────│   分析结果      │
│  力导向图界面    │     │   服务接口      │     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

## 功能特性

- **数据导入**: 生成模拟 NetFlow 数据并导入 Neo4j 图数据库，支持大规模数据
- **节点分析**: 使用 PageRank 算法识别网络中的核心节点
- **社区发现**: 使用 Louvain 算法发现网络中的通信集群
- **异常检测**: 识别高流量、异常端口的可疑通信
- **高性能可视化**: Canvas 渲染的 D3.js 力导向图，支持 5000+ 节点流畅交互
- **自适应渲染**: 根据数据规模自动调整渲染配置，保证流畅体验
- **时间轴回溯**: 支持按时间窗口查询图快照，动态展示网络拓扑演变过程

## 技术栈

## 安装步骤

### 1. 安装 Neo4j

下载并安装 Neo4j Desktop 或使用 Docker:

```bash
docker run -p 7474:7474 -p 7687:7687 -d neo4j:latest
```

默认配置:
- URI: bolt://localhost:7687
- 用户: neo4j
- 密码: password (首次登录需修改)

### 2. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 3. 配置参数

修改 `config/config.py` 中的 Neo4j 连接配置:

```python
NEO4J_CONFIG = {
    "uri": "bolt://localhost:7687",
    "user": "neo4j",
    "password": "your_password",
    "database": "neo4j"
}
```

## 使用方法

### 快速启动（推荐）

```bash
python main.py all
```

这将依次执行：数据生成导入 → 图分析 → 启动 API 服务。

### 分步执行

1. **生成并导入数据**:
```bash
python main.py import
```

2. **运行图分析**:
```bash
python main.py analyze
```

3. **启动 API 服务**:
```bash
python main.py server
```

4. **打开前端界面**:

直接在浏览器中打开 `frontend/index.html` 文件，或使用本地 HTTP 服务器:

```bash
cd frontend
python -m http.server 8080
```

然后访问 http://localhost:8080

## API 接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/graph` | GET | 获取完整图数据（节点+边） |
| `/api/nodes` | GET | 获取所有节点信息 |
| `/api/edges` | GET | 获取所有边信息 |
| `/api/pagerank/top/<n>` | GET | 获取 Top N PageRank 节点 |
| `/api/communities` | GET | 获取社区分布摘要 |
| `/api/statistics` | GET | 获取图统计信息 |
| `/api/node/<ip>` | GET | 获取指定 IP 节点详情 |
| `/api/generate-data` | POST | 生成新的模拟数据 |

## 可视化界面说明

### 节点含义
- **大小**: 代表 PageRank 值，越大表示该节点在网络中越重要
- **颜色**:
  - 红色发光节点: 异常节点（参与可疑通信）
  - 其他颜色: 不同社区（Louvain 算法聚类结果）

### 边含义
- **蓝色**: 正常通信流量
- **红色**: 异常通信流量（高流量、可疑端口等）
- **箭头**: 通信方向

### 时间轴回溯功能

底部时间轴控件支持动态查看网络拓扑随时间的演变：

| 控件 | 功能 |
|------|------|
| ▶/⏸ | 播放/暂停自动播放 |
| ◀ | 上一帧（前一个时间片） |
| ▶ | 下一帧（后一个时间片） |
| ⟲ | 重置到开始位置 |
| 滑块 | 拖动滑块快速跳转到任意时间点 |
| 速度 | 选择播放速度 (0.5x / 1x / 2x / 4x) |

**功能特点**:
- 数据自动缓存：已加载的时间片会被缓存，重复访问无需重新请求
- 平滑过渡：切换时间片时视图自动平滑过渡
- 实时统计：显示当前时间片的节点数和边数

### 交互功能
- **拖拽**: 节点可自由拖动调整位置
- **缩放**: 鼠标滚轮缩放视图
- **悬停**: 显示节点详细信息（IP、PageRank、社区、度数等）
- **点击**: 在右侧面板显示节点完整详情
- **双击节点**: 聚焦并放大该节点
- **双击空白**: 重置视图
- **刷新**: 重新加载数据
- **生成新数据**: 重新生成模拟 NetFlow 数据

## 算法说明

### PageRank 算法
- 用于衡量节点在网络中的重要性
- 基于链接分析的迭代算法
- 考虑节点的入度和出度质量

### Louvain 社区发现算法
- 基于模块度优化的层次聚类算法
- 自动发现网络中的社区结构
- 时间复杂度低，适合大规模网络

## 性能优化

### 前端渲染优化

| 优化技术 | 效果 |
|---------|------|
| **Canvas 替代 SVG** | 渲染性能提升 10-20 倍，支持 5000+ 节点 |
| **视口裁剪** | 只渲染可见区域，减少绘制量 70%+ |
| **批量绘制** | 正常/异常边分批次绘制，减少状态切换 |
| **自适应渲染** | 根据节点数自动调整特效、透明度、节点大小 |
| **动态降级** | FPS < 20 时自动降低渲染质量 |

### 后端算法优化

| 优化技术 | 效果 |
|---------|------|
| **边聚合** | 同 IP 对多条流合并，边数可减少 50%+ |
| **自适应 PageRank** | 大规模数据减少迭代次数 |
| **快速社区发现** | 超大规模数据使用哈希分区替代 Louvain |
| **批量导入** | 字典聚合后批量添加边，提升建图速度 |

## 扩展建议

1. **真实数据接入**: 修改 `data_import.py` 接入真实的 NetFlow/IPFIX 数据源
2. **实时分析**: 添加消息队列（Kafka/RabbitMQ）实现实时流量分析
3. **告警系统**: 基于阈值和异常检测结果触发告警
4. **更多算法**: 集成介数中心性、接近中心性等其他图算法
5. **时间序列**: 添加时间维度，分析流量演变趋势
6. **WebGL 渲染**: 对于超大规模数据（>10000 节点），考虑使用 Three.js WebGL 渲染
