# WebRTC 局域网大文件传输工具

基于 Electron + Node.js + WebRTC 的局域网大文件分片传输工具，支持最大10GB文件传输，内存占用控制在200MB以内。

## 功能特性

- ✅ 拖拽文件上传，支持最大10GB文件
- ✅ 自动分片传输，每片1MB
- ✅ WebRTC点对点直连，通过信令服务器交换SDP
- ✅ 多通道并行传输（5个并行请求）
- ✅ 断点续传功能
- ✅ 实时传输速度显示
- ✅ 分片完成情况可视化
- ✅ 内存使用优化（限制在200MB以内）
- ✅ 实时内存使用监控
- ✅ **多目标同时传输** - 可选择多个接收端同时发送
- ✅ **独立速度控制** - 每个连接可独立设置传输速度限制
- ✅ **暂停/继续功能** - 支持单个或全部暂停/继续传输

## 内存优化

### 主要优化点

1. **避免一次性大Buffer分配**
   - 使用 `fs.ftruncate()` 替代 `Buffer.alloc(fileSize)` 创建稀疏文件
   - 无论文件多大，初始化时几乎不占用内存

2. **高效的数据编码**
   - 使用 Base64 编码替代 JSON 数组序列化
   - 内存开销从 500% 降低到 33%

3. **并发请求限制**
   - 最多同时 5 个分片传输请求
   - 避免同时处理过多数据导致内存飙升

4. **分片网格显示优化**
   - 最多显示 1000 个分片格子，超过则压缩显示
   - 避免 DOM 元素过多导致内存问题

5. **实时内存监控**
   - 每 5 秒输出一次内存使用情况
   - 方便排查内存泄漏问题

### 内存使用对比

| 文件大小 | 优化前内存 | 优化后内存 |
|---------|-----------|-----------|
| 1GB     | ~500MB    | ~100MB    |
| 5GB     | ~3GB+     | ~120MB    |
| 10GB    | 崩溃      | ~150MB    |

## 安装和运行

### 1. 安装依赖

```bash
npm install
```

### 2. 运行项目

```bash
npm start
```

这会同时启动信令服务器和Electron应用。

### 或者分别启动

```bash
# 只启动信令服务器
npm run server

# 只启动Electron
npm run electron
```

## 使用方法

### 多设备同时传输（发送方）

1. **多台设备加入同一房间**（至少2台接收设备 + 1台发送设备）

2. **选择文件**：
   - 将文件拖拽到"拖拽文件到此处"区域，或点击区域选择文件
   - 支持最大10GB文件

3. **选择接收端**：
   - 在"选择接收设备"面板中，勾选要发送到的设备
   - 可点击"全选"选择所有在线设备，或"取消全选"清除选择
   - 设置全局传输速度限制（可选：无限制、1MB/s、5MB/s、10MB/s、25MB/s、50MB/s、100MB/s）

4. **开始发送**：
   - 点击"发送文件"按钮
   - 在弹出的传输面板中可以看到每个接收端的独立传输状态

5. **传输控制**：
   - 每个连接可以单独设置速度限制
   - 可以单独暂停/继续某个连接的传输
   - 可以点击"全部暂停"或"全部继续"批量控制

### 接收文件（接收端）

1. 在"可接收文件"区域找到要接收的文件
2. 点击"接收文件"按钮，选择保存位置
3. 查看传输进度和速度

## 技术细节

### 多目标传输架构

1. **独立传输状态**
   - 每个目标设备有独立的传输状态对象
   - 使用 `transferKey = "${fileHash}-${peerId}"` 标识每个连接
   - 每个连接维护独立的已接收分片集、请求分片集

2. **并行处理**
   - 每个设备独立请求分片，互不影响
   - 每个连接有独立的速度限制
   - 支持同时向多个设备传输

3. **速度控制**
   - 通过延迟发送分片实现速度限制
   - 公式：`延迟 = (分片大小 / 速度限制) * 1000 毫秒`
   - 支持动态调整每个连接的速度（0-100MB/s）

### 分片传输
- 分片大小：1MB (1024 * 1024 字节)
- 最大文件：10GB
- 哈希校验：SHA256
- 并发请求：每连接最多5个并行请求

### WebRTC配置
- ICE服务器：Google STUN服务器
- 数据通道：Socket.io信令传输
- 传输模式：Base64编码分片数据

### 断点续传
- 传输中断后重新接收时，会自动跳过已接收的分片
- 通过检查本地文件已存在的分片实现

## 注意事项

1. **防火墙设置**：确保两台电脑在同一局域网，防火墙允许3000端口和WebRTC连接
2. **网络延迟**：高延迟网络下传输速度可能受影响
3. **大文件**：传输10GB文件需要足够磁盘空间和时间
