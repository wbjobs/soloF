# 离线法律卷宗检索工具 - 快速入门

## 📁 项目结构

```
f58/
├── app.py              # Streamlit 界面主程序
├── main.py             # 命令行工具
├── start.bat           # Windows 一键启动脚本
├── requirements.txt    # Python 依赖
├── .env                # 环境配置
├── src/
│   ├── config.py       # 配置管理
│   ├── data_processor.py  # 数据处理模块
│   ├── retriever.py    # 检索模块
│   └── generator.py    # 生成模块
├── models/             # 模型存放目录
├── data/               # 测试数据目录
└── chroma_db/          # 向量数据库目录
```

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 下载 LLM 模型

1. 访问 https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct-GGUF
2. 下载 `llama-3-8b-instruct.Q4_K_M.gguf`
3. 将文件放到 `models/` 目录下

### 3. 启动应用

**方式一：使用启动脚本（推荐）**
```bash
start.bat
```

**方式二：直接运行**
```bash
streamlit run app.py
```

### 4. 使用流程

1. 在侧边栏上传 PDF 法律卷宗
2. 点击"处理并索引文档"
3. 在主界面输入问题
4. 查看回答和引用来源

## 🖥️ 命令行使用

### 批量处理文档
```bash
python main.py process ./data
```

### 检索相关片段
```bash
python main.py search "本案的争议焦点"
```

### 智能问答
```bash
python main.py ask "被告的答辩意见是什么？"
```

## ⚙️ 配置说明

编辑 `.env` 文件可调整以下参数：

- `CHUNK_SIZE`: 文档切片大小（默认 500 字符）
- `CHUNK_OVERLAP`: 切片重叠大小（默认 50 字符）
- `TOP_K`: 检索返回的相关片段数量（默认 3）
- `LLM_N_CTX`: LLM 上下文窗口大小（默认 4096）
- `LLM_N_GPU_LAYERS`: GPU 加速层数（-1 表示全部）

## 🔗 多跳检索能力

针对需要跨文档推理的复杂问题，本工具实现了多跳检索功能。

### 支持的问题类型

| 类型 | 触发关键词 | 示例 |
|------|-----------|------|
| 对比分析型 | 对比、比较、差异、区别、异同 | "对比案例A和案例B的判决差异" |
| 关系分析型 | 分析.*关系、关联、影响、因果 | "分析合同违约与赔偿责任的关系" |
| 综合总结型 | 总结.*所有、汇总、综合、整体 | "总结所有相关案例的裁判要点" |
| 列举型 | 分别、各个、每个、逐一 | "分别说明每个被告的答辩意见" |
| 组合型 | 结合.*和、同时考虑 | "结合刑法和民法典分析该行为" |
| 因果分析型 | 为什么、原因、导致、造成 | "为什么会出现这样的判决结果" |

### 工作原理

1. **问题类型检测**：自动识别问题是否需要多跳检索
2. **查询拆解**：将复杂问题分解为多个子查询
3. **多轮检索**：对每个子查询独立检索相关文档
4. **结果聚合**：去重、合并多轮检索结果
5. **上下文构建**：按子查询组织检索结果，便于模型理解
6. **回答生成**：基于聚合的上下文生成综合回答

### 界面功能

- **多跳检索开关**：侧边栏可开启/关闭多跳检索
- **强制多跳**：即使简单问题也使用多跳检索
- **问题类型提示**：输入问题时自动检测并提示类型
- **子查询展示**：可展开查看系统生成的子查询
- **检索统计**：显示多跳检索的详细统计信息

### 命令行使用

```bash
# 默认启用多跳检索
python main.py ask "对比案例A和案例B的判决差异"

# 禁用多跳检索
python main.py ask "本案的争议焦点是什么" --no-multi-hop

# 强制使用多跳检索
python main.py ask "原告的诉讼请求有哪些" --force-multi-hop
```

## 📝 注意事项

1. **首次运行**会自动下载 BGE-M3 嵌入模型，需要联网
2. LLM 模型需要手动下载并放到 `models/` 目录
3. 所有数据处理均在本地完成，不会上传到任何服务器
4. 建议使用 Python 3.10+ 版本
5. 如遇到引用不准确问题，可尝试：
   - 减小 `CHUNK_SIZE` 提高检索精度
   - 增大 `TOP_K` 获取更多相关片段
   - 调整提问方式，更具体明确
6. 多跳检索会增加检索时间，适用于复杂问题
7. 对于简单问题，可关闭多跳检索提高响应速度
