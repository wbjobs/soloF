# 火焰图功能使用指南

## 概述

`trace-cli` 支持生成火焰图数据，用于可视化请求链路中的性能瓶颈。火焰图是一种强大的性能分析工具，可以直观地展示请求在各个服务中的耗时分布。

## 工作原理

### 时间分析机制

1. **毫秒级时间戳解析**：精确解析日志中的时间戳，支持多种格式：
   - `2024-01-15T10:30:01.123Z`
   - `2024-01-15 10:30:01.123`
   - `2024/01/15 10:30:01,123`

2. **耗时自动计算**：
   - 根据相邻日志条目的时间戳差值计算耗时
   - 支持从日志中提取显式的 `duration` 字段

3. **服务调用栈构建**：
   - 按时间顺序排列日志条目
   - 将服务调用关系转换为火焰图栈结构

## 快速开始

### 1. 生成火焰图数据

```bash
# 使用演示模式生成火焰图数据（最快体验）
trace-cli --demo -t abc123def456 --flame-graph flamegraph.txt --stats

# 使用本地日志文件
trace-cli \
  -l gateway:cyan:sample_logs/gateway.log \
  -l auth:green:sample_logs/auth.log \
  -l order:yellow:sample_logs/order.log \
  -t abc123def456 \
  --flame-graph flamegraph.txt \
  --stats

# 使用远程 SSH 日志
trace-cli -c config.json -t trace-id-123 --flame-graph flamegraph.txt --stats
```

### 2. 查看生成的数据

火焰图数据文件（`flamegraph.txt`）采用折叠栈格式：

```
# Flame Graph Data for Trace-ID: abc123def456
# Generated by trace-cli
# Total entries: 10
# Total duration: 1377 ms
# Format: stack;frames duration_ms

trace;gateway 2
trace;gateway;auth 5
trace;auth 55
trace;auth;gateway 10
trace;gateway;order 10
trace;order 190
trace;order;order 600
trace;order 500
trace 1377
```

### 3. 生成可视化火焰图

使用 Brendan Gregg 的 FlameGraph 工具生成 SVG 火焰图：

```bash
# 下载 FlameGraph 工具
git clone https://github.com/brendangregg/FlameGraph.git

# 生成火焰图 SVG
./FlameGraph/flamegraph.pl flamegraph.txt > flamegraph.svg

# 在浏览器中打开
open flamegraph.svg
```

## 命令行选项

| 选项 | 说明 |
|------|------|
| `--flame-graph <path>` | 生成火焰图数据文件（折叠栈格式） |
| `--stats` | 显示按服务统计的耗时分布 |

## 火焰图解读

### 示例输出

```
Per-Service Time Breakdown for Trace-ID: abc123def456
========================================
gateway      1377 ms (100.0%) |==================================================
auth          610 ms ( 44.3%) |=====================
order        1290 ms ( 93.7%) |=============================================

Total: 1377 ms
```

### 火焰图含义

```
┌─────────────────────────────────────────────────┐
│                     trace                       │
├─────────────────┬───────────────────────────────┤
│    gateway      │             order             │
├────────┬────────┴─────────────┬─────────────────┤
│  auth  │                       │                 │
└────────┴───────────────────────┴─────────────────┘
```

- **X 轴**：表示累计耗时（宽度越大，耗时越长）
- **Y 轴**：表示调用栈深度（从下到上是调用关系）
- **每个矩形**：表示一个函数/服务调用，宽度表示耗时占比

### 性能瓶颈识别

1. **宽矩形**：宽度大的矩形表示该服务耗时较长，可能是性能瓶颈
2. **高栈**：调用栈很深可能表示链路过长
3. **平的火焰图**：多个并排的宽矩形表示并行处理或多处耗时

## 支持的日志格式

### 自动识别的时间戳格式

工具可以自动解析以下时间戳格式：

1. **ISO 8601 格式**：
   ```
   2024-01-15T10:30:01.123Z
   2024-01-15T10:30:01.123456
   2024-01-15T10:30:01,123
   ```

2. **标准格式**：
   ```
   2024-01-15 10:30:01.123
   2024/01/15 10:30:01
   Jan 15 10:30:01
   ```

### 支持的 Trace-ID 格式

```
trace_id=abc123def456
traceId=abc123def456
"trace_id":"abc123def456"
X-B3-TraceId: abc123def456
```

### 支持的 Duration 格式

```
duration=123
duration_ms=123
latency=123.45
took=123
elapsed=0.123
```

## 完整使用示例

### 步骤 1：准备日志文件

确保你的日志包含：
- 时间戳（精确到毫秒）
- Trace-ID
- 服务标识

示例日志格式：
```
2024-01-15T10:30:01.123Z INFO  [gateway] trace_id=abc123def456 Request received
2024-01-15T10:30:01.130Z INFO  [auth] trace_id=abc123def456 Validating token
2024-01-15T10:30:01.200Z INFO  [order] trace_id=abc123def456 Processing order
```

### 步骤 2：生成火焰图数据

```bash
trace-cli \
  -l gateway:cyan:logs/gateway.log \
  -l auth:green:logs/auth.log \
  -l order:yellow:logs/order.log \
  -t abc123def456 \
  --flame-graph flamegraph.txt \
  --stats
```

### 步骤 3：生成 SVG 火焰图

```bash
# 安装火焰图工具
git clone https://github.com/brendangregg/FlameGraph.git

# 生成 SVG
./FlameGraph/flamegraph.pl flamegraph.txt > flamegraph.svg

# 查看
browser flamegraph.svg
```

## 高级用法

### 自定义火焰图

你可以修改生成的折叠栈文件，添加更多上下文：

```
# 添加自定义标签
trace;gateway;request-validation 50
trace;gateway;auth-call 100
trace;auth;token-verify 80
trace;auth;db-query 20
```

### 对比分析

为不同时间段或不同 Trace-ID 生成火焰图进行对比：

```bash
# 生成多个火焰图数据
trace-cli -t trace-1 --flame-graph fg1.txt
trace-cli -t trace-2 --flame-graph fg2.txt

# 生成差异化火焰图
./FlameGraph/difffolded.pl fg1.txt fg2.txt | ./FlameGraph/flamegraph.pl > diff.svg
```

## 注意事项

1. **时间同步**：确保所有服务器的时钟同步（建议使用 NTP）
2. **时区**：所有日志应使用相同的时区，建议使用 UTC
3. **日志完整性**：确保收集到完整的请求链路日志
4. **采样率**：对于高流量服务，考虑使用采样来减少数据量

## 故障排除

### 火焰图为空或数据很少

- 检查 Trace-ID 是否正确
- 确认日志中包含时间戳和 Trace-ID
- 验证日志格式是否被正确解析

### 时间计算不正确

- 检查日志中的时间戳格式
- 确保所有服务的时钟同步
- 查看生成的 `.txt` 文件中的详细时间戳

### 生成的 SVG 无法查看

- 确保使用 Brendan Gregg 的 flamegraph.pl 脚本
- 检查输入文件格式是否正确
- 尝试使用不同的浏览器打开
